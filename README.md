# 🍽️ Taste Finder

Taste Finder helps you quickly figure out what to cook using ingredients you already have in your kitchen.

* 🔍 **Ingredient Search:** Input leftovers or pantry items to find matching recipes instantly.
* 🌶️ **Taste & Diet Filters:** Narrow down dishes by flavor (spicy, sweet, umami) or dietary preferences (vegan, keto, gluten-free).
* 📖 **Instant Instructions:** Get step-by-step cooking directions and nutritional info in seconds.
